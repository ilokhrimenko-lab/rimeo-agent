# Внимание: этот Python-агент не используется

Python-файлы в этой папке (`api_server.py`, `ui_app.py` и др.) — это **устаревший прототип агента**. В продакшне он не используется.

## Актуальные агенты

| ОС | Папка |
|----|-------|
| macOS (Apple Silicon / ARM64) | `macos_arm64/` |
| Windows | `windows_csharp/` |

## Сборка агента

Пересборка macOS-агента:
```bash
./release_mac.sh
```

Скрипт делает коммит + тег (`mac-v1.0-buildNNN`) — **без тега CI не стартует**. Релиз должен унести
**два** mac-ассета: `RimeoAgent_mac.zip` (автообновление, имя захардкожено в `UpdateChecker.swift`) и
`RimeoAgent.dmg` (установщик для людей). Подробности → `README.md`, раздел «Building & releasing».

## Инструкция для Claude

- Вопрос про агент на **macOS** → читай код в `macos_arm64/`
- Вопрос про агент на **Windows** → читай код в `windows_csharp/`
- Если не понятно, какая ОС имеется в виду — **спроси пользователя** прежде чем идти в код
- Не редактируй Python-файлы в этой папке — они не влияют на работающий агент
