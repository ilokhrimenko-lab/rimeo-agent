# Rimeo Agent

### Your Rekordbox DJ library, on every device.

Native **macOS** and **Windows** companion app for [Rimeo](https://rimeo.app). It runs on the computer that holds your music and lets the Rimeo iPhone app and web player stream your Rekordbox library, at home or from anywhere. Your files never leave your machine.

This repository hosts the official signed releases of Rimeo Agent. The installed app checks these releases for updates.

- **macOS:** `RimeoAgent.dmg` (Developer ID signed and notarized by Apple).
- **Windows:** `RimeoAgentSetup_win.exe` (x64) and `RimeoAgentSetup_win-arm64.exe` (ARM).

The easiest way to get started is [rimeo.app/download](https://rimeo.app/download).
